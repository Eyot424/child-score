# 徐瑾熙的星星

给 6 岁小朋友的行为积分系统。单文件网页，双击打开即用，不需要联网、不需要服务器。

```
index.html      应用本体（单文件，无依赖）
DESIGN.md       积分规则设计（分值怎么定的、为什么这么定）
DESIGN-WEB.md   网页方案设计（技术选型、页面结构、数据模型）
```

## 用法

双击 `index.html`，用 Chrome 或 Edge 打开。

**第一次打开先做一件事**：点顶部横幅的「存到文件」，选一个位置保存 `徐瑾熙的星星.json`。
之后每次改动都会自动写进那个文件，浏览器怎么清理数据都不会丢。
（只存浏览器 localStorage 的话，`file://` 下所有本地网页共用一个存储桶，清一次就全没了。）

建议把这个 json 放在网盘同步目录里。

## 规则一句话版

| | |
|---|---|
| **得星星** | 每天 6 件事：刷牙、按时睡觉、认真学习、帮忙干活、管好脾气、自己好好吃饭。做到一件 1 颗 |
| **得太阳** | 一天拿到 5 颗以上星星 = 1 个太阳（最多错一件） |
| **扣** | 小脾气 → 那颗星拿不到；情绪失控 → 当天没太阳；打人 → 星星清零再扣 1 个太阳 |
| **星星换** | 玩 20 分钟电子设备 1⭐ · 补一个太阳 20⭐ |
| **太阳换** | 零食 1☀️ · 玩具 10☀️ · 游乐场 20☀️ · 旅游 60☀️ |

**生气可以，失控不行，动手最严重。**

## 上线节奏

前两周是**基线期**：星星太阳照常拿，扣分只记录不生效。目的是先让她相信这套东西真能换到东西，
同时拿到真实的失控频率和各格达成率——两周后用这些数据校准里程碑数字。
基线期开关在「设置」里，到期会自动弹提醒。

详见 [DESIGN.md](DESIGN.md) §6。
