# 徐瑾熙的星星

给 6 岁小朋友的行为积分系统。单文件网页，双击打开即用，不需要联网、不需要服务器。

```
public/index.html      应用本体（单文件，无依赖）
functions/api/data.js  同步 API（Cloudflare Pages Function + KV）
wrangler.toml          部署配置
DEPLOY.md              部署到外网的五步
DESIGN.md              积分规则设计（分值怎么定的、为什么这么定）
DESIGN-WEB.md          网页方案设计（技术选型、页面结构、数据模型）
```

## 两种用法

### 一、部署到外网（多设备同一份数据）

照着 [DEPLOY.md](DEPLOY.md) 走五步，得到一个 `https://xxx.pages.dev` 网址。
手机电脑都打开它，第一次输一次家庭密码，之后任何设备上的改动其他设备都能看到。

网址是公开的，**但没有家庭密码谁也读不到、改不了数据**。

### 二、纯本地（双击就用）

直接双击 `public/index.html`，用 Chrome 或 Edge 打开。页面会自动进入本地模式，不去连服务器。

这时候建议点顶部横幅的「存到本地文件」，选个位置保存 `徐瑾熙的星星.json`——
之后每次改动都写进那个文件。只靠浏览器 localStorage 的话，`file://` 下所有本地网页
共用一个存储桶，清一次浏览数据就全没了。

同一个 html 文件，两种模式自动切换，不用改代码。

## 规则一句话版

| | |
|---|---|
| **得星星** | 每天 6 件事：刷牙、按时睡觉、认真学习、帮忙干活、管好脾气、自己好好吃饭。做到一件 1 颗 |
| **得太阳** | 一天拿到 5 颗以上星星 = 1 个太阳（最多错一件） |
| **扣** | 小脾气 → 那颗星拿不到；情绪失控 → 当天没太阳；打人 → 星星清零再扣 1 个太阳 |
| **星星换** | 玩 20 分钟电子设备 1⭐ · 补一个太阳 20⭐ |
| **太阳换** | 零食 1☀️ · 玩具 10☀️ · 游乐场 20☀️ · 旅游 60☀️ |

**生气可以，失控不行，动手最严重。**

## 上线节奏

前两周是**基线期**：星星太阳照常拿，扣分只记录不生效。目的是先让她相信这套东西真能换到东西，
同时拿到真实的失控频率和各格达成率——两周后用这些数据校准里程碑数字。
基线期开关在「设置」里，到期会自动弹提醒。

详见 [DESIGN.md](DESIGN.md) §6。
