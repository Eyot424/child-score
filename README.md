# 徐瑾熙的星星

给 6 岁小朋友的行为积分系统。单文件网页，双击打开即用，不需要联网、不需要服务器。

```
index.html        应用本体（单文件，无依赖，无构建）
data/stars.json   数据（由应用自动提交，不用手改）
SYNC.md           多设备同步怎么配
DESIGN.md         积分规则设计（分值怎么定的、为什么这么定）
DESIGN-WEB.md     网页方案设计（技术选型、页面结构、数据模型）
```

在线版：**https://eyot424.github.io/child-score/**

## 用法

**双击 `index.html`**，用 Chrome 或 Edge 打开。不需要服务器，不需要构建。

### 想在手机和电脑上共用同一份数据

照着 [SYNC.md](SYNC.md) 配一下：数据存成这个仓库里的 `data/stars.json`，
应用直接调 GitHub API 读写，每次改动提交一次。

**没有后端。** GitHub API 允许从 `file://` 跨域调用，所以电脑上双击本地文件就能同步；
手机上把 `public/` 挂成 GitHub Pages 拿一个网址就行。

顺带白得一份完整的修改历史 —— 每天的记录都是一个 commit，能回看能回滚。

### 不想同步

什么都不用配。数据存在浏览器里，另外可以在设置里绑一个本地 .json 文件做备份
（`file://` 下所有本地网页共用一个存储桶，只靠 localStorage 清一次浏览数据就全没了）。

同一个 html 文件，两种模式自动切换。

## 规则一句话版

| | |
|---|---|
| **得星星** | 每天 6 件事：刷牙、按时睡觉、认真学习、帮忙干活、管好脾气、自己好好吃饭。做到一件 1 颗 |
| **得太阳** | 一天拿到 5 颗以上星星 = 1 个太阳（最多错一件） |
| **扣** | 小脾气 → 那颗星拿不到；情绪失控 → 当天没太阳；打人 → 星星清零再扣 1 个太阳 |
| **星星换** | 玩 20 分钟电子设备 1⭐ · 补一个太阳 20⭐ |
| **太阳换** | 零食 1☀️ · 小玩具 10☀️ · 大玩具**或**游乐场 20☀️（二选一）· 出国旅游 60☀️ |

**生气可以，失控不行，动手最严重。**

## 上线节奏

前两周是**基线期**：星星太阳照常拿，扣分只记录不生效。目的是先让她相信这套东西真能换到东西，
同时拿到真实的失控频率和各格达成率——两周后用这些数据校准里程碑数字。
基线期开关在「设置」里，到期会自动弹提醒。

详见 [DESIGN.md](DESIGN.md) §6。
